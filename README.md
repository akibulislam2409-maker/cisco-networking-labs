# 🌐 Cisco Networking Labs

Network design and configuration labs built in **Cisco Packet Tracer** for **COMP515 Fundamentals of Computer Networking** (Grade: A+).

## Labs
| Folder | What I built |
|---|---|
| `campus-network-rip/` | Two routers serving a student network and a staff network, a WAN link, **RIPv2** routing, interface configuration, verification |
| `vlan-trunking/` | **VLAN** creation, access ports, **802.1Q trunks** between switches, ping tests, **Telnet** remote access |
| `enterprise-network/` | Enterprise network tasks: router and switch configuration, VLANs for HR, Sales, IT and Management, PC addressing, wireless |

## Theory covered
Ethernet (802.3) and Wi-Fi (802.11) standards, topologies, the OSI model, TCP vs UDP, IPv4 addressing and subnetting.
